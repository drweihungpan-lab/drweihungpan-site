Everything about this stream is built from the collection it lives in: the
stream index, this entry page, and the **Faith** item in the main navigation.

never show an empty section here.

`src/content/writing/` with the frontmatter block above and writing the piece.

missing date, a misspelled key, a stream that does not exist — fails the build
instead of reaching a reader.
